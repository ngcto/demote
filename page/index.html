Demote

Credential order: available → soft-demoted → hard-demoted.

Setup: use Magpie’s authenticated web management API. In the native desktop app, enable Browser access in Settings → Network and sharing. That setting is hidden in the web UI because browser access is already running. For magpie web / serve --web, supply MAGPIE_WEB_KEY in the host environment. Demote only connects over loopback and never enables Browser access itself.

Orders and tier classifications persist across restarts. No automatic recovery or expiry. No accounts are deleted or disabled. Subscription rearrangement can switch the agent’s primary sign-in; Keep login prevents that. Turning Demote off does not undo saved changes.
